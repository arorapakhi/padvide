# PadVide

**Care, stocked and accounted for.**

Menstrual product accessibility and inventory monitoring for public middle and high schools.

## The Problem

Schools may provide free menstrual products, but dispensers run empty, break, or
become inaccessible without administrators knowing. A student who finds an empty
box misses class, goes home, or goes without.

## What PadVide Does

**Dashboard** - Live status of all 12 dispensers across three buildings.
Statuses are *calculated* from inventory, capacity, sensor health, and reading
age, so the system can never report "stocked" for an empty dispenser.
Hardware faults outrank inventory readings, because a broken sensor's number
cannot be trusted.

**Setup** - School identity, location, community need level, verified restocker
contact, dispenser capacities, and the two-week monitoring period.
Higher-need schools receive a larger safety buffer so dispensers never run dry.

**Restock Agent** - Rolling usage averages, week-over-week trend changes,
projected days until empty, restock-by dates, and exact unit counts to bring.
Generates a restock request message addressed to the verified restocker and
keeps a timestamped audit log.

## Technology

Python, Streamlit, Pandas, SQLite, Plotly
